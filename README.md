# NV-center sensing simulation: ODMR, coherence and dynamical decoupling

Simulations of a single nitrogen-vacancy (NV) center in diamond, from the spin Hamiltonian up to magnetometer sensitivity under correlated noise. Everything is classical-noise simulation with ideal or error-prone pulses, written in Python with QuTiP and NumPy.

## What this project does

1. Builds the NV ground-state Hamiltonian (zero-field splitting, Zeeman term, 14N hyperfine) and checks it against analytic resonances.
2. Simulates ODMR spectra, Rabi oscillations and Ramsey fringes.
3. Adds Ornstein-Uhlenbeck (OU) detuning noise and compares free decay, Hahn echo and CPMG sequences.
4. Converts coherence times into a shot-noise-limited AC magnetometer sensitivity.
5. Studies how the benefit of dynamical decoupling depends on the noise correlation time, and how pulse errors affect CPMG and XY8.

Main numbers (noise sigma = 0.2 MHz, correlation time 2 us):

| Sequence | T2 (us) | Best sensitivity (nT/sqrt(Hz)) |
|---|---|---|
| Free decay / Ramsey (DC) | 1.25 | 763.8 |
| Hahn echo (N=1) | 2.94 | 506.5 |
| CPMG N=2 | 4.21 | 375.4 |
| CPMG N=4 | 6.47 | 271.0 |
| CPMG N=8 | 10.08 | 195.0 |
| CPMG N=16 | 15.76 | 146.2 |

- T2 scales roughly as N^0.62 for this noise. CPMG-16 improves sensitivity 3.46x over the Hahn echo.
- Sweeping the correlation time, the fitted exponent rises from 0.49 (tau_c = 0.5 us) to 0.66 (tau_c = 32 and 128 us), approaching the theoretical 2/3 for slow noise. The Hahn echo gain over free decay grows from 1.5x to 9.5x.
- With flip-angle error eps in the pi pulses, CPMG preserves coherence only for a state aligned with its pulse axis. For the other state its signal oscillates because errors add coherently (8 pulses over-rotate by about 8*pi*eps in total). XY8 stays near the error-free value for both states.

## Validation

- On-axis resonances match D +/- gamma*B exactly; off-axis splittings follow the expected angular dependence; the 14N triplet is spaced by 2.14 MHz.
- Rabi oscillations match the analytic formula to about 1e-5.
- Fitted Ramsey T2* is 1.115 us against a theoretical 1.125 us.
- Free decay under OU noise matches the exact analytic formula (maximum deviation 0.04, consistent with the sampling error of 2000 noise realizations).
- In the slow-noise limit the Hahn echo T2 follows the analytic result (12*tau_c/(2*pi*sigma)^2)^(1/3) to within about 5%, and T2 vs N follows N^(2/3) when pulses sit exactly on the time grid.
- A numerical artifact was found and fixed: when pulse times are rounded to an arbitrary grid, quasi-static noise is not fully refocused and the fitted exponent drops. Pulses are now placed exactly on time steps (`aligned_times` in `src/noise.py`).
- `tests/` contains automated checks of the Hamiltonian resonances and the OU free-decay formula.

## Assumptions and limitations

- Sensitivity uses assumed readout parameters, not measurements: 0.03 detected photons per readout, 30% contrast and 3 us overhead per shot (readout noise factor 35.5). Absolute nT/sqrt(Hz) values depend on these. The relative improvement between sequences matters more.
- Each sequence senses an AC field at a different frequency, N/(2T), so sensitivities are best-case per sequence, not at a fixed signal frequency. Ramsey senses DC fields and is shown for reference.
- Noise is classical OU detuning noise with a correlation time of microseconds. Real carbon-13 baths are much slower, so the T2 values here (microseconds) are not comparable with experimental echo T2 values (milliseconds). The tau_c sweep shows the trend toward that regime.
- Pulses are instantaneous. Pulse errors are flip-angle errors only, and the pi/2 preparation and readout pulses are ideal.
- No comparison with experimental data yet.

## Reproducing the results

```
git clone https://github.com/Chancellor-Jesvin/nv-sensing-sim.git
cd nv-sensing-sim
python -m venv .venv
.venv\Scripts\activate          (Windows; on Linux/macOS: source .venv/bin/activate)
pip install -r requirements.txt
python -m pytest
```

Then run the notebooks in order (Restart and Run All). Notebook 03 takes a few minutes because of the noise sweeps.
